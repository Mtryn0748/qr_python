# 🗣️ Sesli Kitap Projesi 🧩

Bu proje, **PDF dosyalarındaki metni sesli olarak çeviren** bir Python uygulamasıdır.  
Kullanıcı, bir PDF dosyası seçerek metni **sesli kitap formatına** dönüştürebilir.
## 📚 Kullanılan Kütüphaneler {
- **PyPDF** → PDF dosyalarından metin çıkarmak için
- **gtts** → Metni sesli çevirerek MP3 olarak kaydetmek için
- **tkinter** → Dosya seçimi ve arayüz yönetimi için
- **os** → MP3 dosyasını açmak ve sistem işlemleri için


## 🛠️ Nasıl Kullanılır?
1. **PDF seç** → Arayüzde "PDF SEÇ" butonuna bas.
2. **Sesli çevir** → Seçilen PDF'deki metin, ses dosyasına dönüştürülür.
3. **Sesli oynat** → MP3 dosyası otomatik olarak açılır.
